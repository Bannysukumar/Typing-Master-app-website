## Getting Started

```bash
git clone https://github.com/Bannysukumar/Typing-Master-app-website.git
cd Typing-Master-app-website
npm install
npm run dev
```

Scripts defined in package.json:

- `npm run dev` — `vite`
- `npm run build` — `vite build`
